## 🚀 Employee Raise Issue (ServiceNow Project)

An enterprise-grade ServiceNow workflow application designed to streamline and automate merit-based compensation reviews. This project replaces traditional, opaque budget-capped salary review processes with a transparent, data-driven system that bridges high-performing employee contributions with automated HR evaluations and market benchmarks.

### ✨ Key Features
* **Custom Scoped Application:** Isolated architecture built using ServiceNow Application Studio for secure role-based access control.
* **Automated Workflow Routing:** Uses Flow Designer to dynamically evaluate tenure and performance criteria, routing approval requests seamlessly.
* **Transparent Service Portal Integration:** Allows employees to track salary review requests without bureaucratic friction.
* **Data-Driven Evaluation:** Integrates performance metrics and market benchmark data to eliminate subjective bias and arbitrary budget caps.
